# AI engine test index

Update this index in the same PR whenever a test family is added, moved, or changes coverage. Run commands from the workspace root. Initialize the pinned fixture submodules with `git submodule update --init` for the core, Parquet and SQL suites.

## Reusable DataFusion tests

| Test family                                | Failure modes                                                                                 | Crate and target                            | Lane    | Features or fixtures                                                 | Local replay                                                                                                           | Known slow path                            |
| ------------------------------------------ | --------------------------------------------------------------------------------------------- | ------------------------------------------- | ------- | -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| Core DataFrame and execution tests         | Public API results, schema and execution regressions                                          | `datafusion` / `core_integration`           | pr      | Defaults, `testing` and `datafusion-testing`                         | `cargo test --locked -p datafusion --test core_integration dataframe`                                                  | First compile, full integration target     |
| Parquet scan integration                   | Pruning, range/split handling, schema coercion and ordering regressions                       | `datafusion` / `parquet_integration`        | pr      | Default Parquet, `parquet-testing`                                   | `cargo test --locked -p datafusion --test parquet_integration`                                                         | Fixture checkout and full scan suite       |
| LLM planner, executor and scripted backend | Unnecessary inference, NULL and row alignment, plan rejection and backend harness regressions | `datafusion` / `llm`                        | pr      | `llm`, scripted providers and generated Parquet                      | `cargo test --locked -p datafusion --features llm --test llm`                                                          | First core compile                         |
| LLM differential fuzz                      | Planner/executor disagreement with the row oracle                                             | `datafusion` / `llm`                        | nightly | Fixed seed, `LLM_FUZZ_REPLAY=dataset_seed,case_seed` for one failure | `LLM_FUZZ_CASES=1000 LLM_FUZZ_SEED=2026 cargo test --locked -p datafusion --features llm --test llm differential_fuzz` | Case count                                 |
| Projection optimizer unit tests            | Loss of expression dependencies and incorrect unused-projection pruning                       | `datafusion-optimizer` / library            | pr      | Generated plans                                                      | `cargo test --locked -p datafusion-optimizer --lib optimize_projections`                                               | First compile                              |
| Execution fuzz suites                      | Limit, merge, spill, memory and data-dependent execution divergences                          | `datafusion-fuzz` / `fuzz`                  | nightly | `extended_tests`, seeded fixture generators                          | `cargo xtask ci step test fuzz`                                                                                        | Iterations and spill I/O                   |
| SQL logic tests                            | Wrong rows, types, plans and expected SQL errors                                              | `datafusion-sqllogictest` / `sqllogictests` | pr      | Checked-in `.slt` files and fixture submodules                       | `cargo test --locked --profile ci -p datafusion-sqllogictest --test sqllogictests -- aggregate.slt`                    | Full corpus and optional external backends |
